✔️ Greenly – E-commerce Frontend + Admin Panel

Greenly is a modern, fully responsive e-commerce web application built using React + Vite.
This project includes a complete Admin Panel for managing products and orders, along with a clean user interface for customers.

🚀 Features

🛒 User Features

Browse all products
View product details
Add to car
Update quantity
Checkout flow
Address selection
Order summary page
Responsive design

🛠️ Admin Panel

Admin Login
Add Product
Product List
Delete or Update Product
Orders List
Sidebar Navigation
Fully responsive layout

🧩 Tech Stack

React.js (Vite)
React Router DOM
Tailwind CSS
React Context API
Lucide Icons
React Hot Toast
